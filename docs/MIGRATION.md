## 安全与恢复

统一构建使用项目内独立临时目录和排他锁，全部游戏与首页完成后再替换已识别的合集产物。若发现 `dist/` 没有本项目 manifest，会拒绝覆盖。并发构建会明确失败；异常中断遗留的锁需先确认进程状态，再按本地路径人工处理，不无限等待或自动删除其他进程的锁。

原始工程与旧构建已在本地忽略目录内保存用于对照。无数据库或持久化格式变化，游戏战绩键保持不变。源码迁移不等于服务器发布；未来部署需选择合集或单游戏产物，再单独执行部署验收。

工程迁移阶段没有初始化项目 Git 仓库、暂存、提交、创建标签或推送；后续源码发布独立于该轮迁移和服务器部署。
