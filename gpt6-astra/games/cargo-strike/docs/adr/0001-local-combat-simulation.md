# ADR 0001：独立本地战斗模拟与统一实体地图

日期：2026-11-14。状态：采用。

## 目标与边界

提供可以独立分享、离线启动的运输船主题 FPS。单个浏览器拥有整个对局；没有账号、后端、多租户、网络同步或服务端权威性的需求。游戏使用既有 Three.js 0.187.0 / TypeScript / Vite 依赖版本，不新增运行时依赖，不与其他游戏共享可变游戏状态。

## 设计

- `game/` 为无 DOM / Three.js 依赖的战斗模型。Match 持有 Actor、武器弹药、计分、时间、复活和有限手雷集合。事件向渲染、声音和 HUD 单向传递。
- `game/map.ts` 声明关卡实体尺寸，同一份实体用于世界绘制、玩家碰撞、子弹遮挡和导航可通行性。桥楼、吊机、海面与栏杆细节属于边界外装饰。
- 固定 60 Hz 模拟，每次渲染最多补 5 步，避免切换标签页后无限追帧。后台和失焦时暂停整个对局。极低帧率下模拟会变慢，不丢弃生命或计分事件以追赶墙钟。
- 地面 AI 使用四邻接格网 BFS，搜索空间有界；每个机器人 2–4 秒刷新一条路线，交火时优先有视线的对手，不能穿墙射击。AI 不攀登高台，高台通路由玩家使用。
- 即时子弹射线先计算最近场景遮挡，再比较敌人头部球体和身体包围盒；友军免伤。弹药仅在实际射击 / 完成换弹时变化；切枪取消当前换弹，不生成新弹药。
- `render/` 负责合批静态几何、程序化纹理、光影、武器视图、角色和有界粒子。第一人称武器独立绘制，避免靠近墙体时穿模消失。
- `input.ts` 负责键鼠 / 触控和生命周期清理；`ui/` 负责界面；`audio.ts` 使用有界、自动释放的音频节点；设置存储失败不影响当前游玩。
- 开发诊断仅在 Vite 开发模式且 URL 带 `?qa` 时存在。生产构建禁止包含诊断全局和外部运行时资源，独立 HTML 设置 `connect-src 'none'`。

## 取舍与恢复

程序化模型保证离线、文件小和可维护性，但不是原作资产级别的视觉复刻。射线武器、简化身体碰撞和格网 AI 属于此版本的明确规则。后续若引入真实联网，应新建服务端权威状态边界，不让现有浏览器自报击杀成为可信数据。

没有业务数据迁移。删除本游戏偏好键 `cargo-strike.preferences.v1` 只会恢复默认设置。游戏以独立目录注册到清单，可撤下条目而不修改其他游戏。Git 提交与推送须由用户明确授权，本地验证不自动触发源码发布或服务器部署。
