## 本轮发现并修复

1. **Phaser 内嵌 SVG 加载失败**：其 XHR loader 将 data URI 内容按 base64 解码。改为明确 base64 编码，浏览器重试后正常加载。
2. **角色渐变引用冲突**：多个 inline SVG 共享渐变 ID，导致不同角色串色，或结算引用到隐藏面板中的渐变而变白。改用每个实例独立的渐变标识，增加唯一性测试并复核大厅与结算。
3. **短按输入遗漏**：按下与松开均发生在两个模拟帧之间时，单纯检查 held 状态会漏掉方向。新增一次性方向缓冲，在下一次可移动时消费，失焦 / 暂停清理；增加对应自动化回归。
4. **慢帧下对局计时偏慢**：Phaser 默认 `smoothStep` 会替换超过最小帧率阈值的 delta。本项目已有固定步长累计，关闭额外平滑，避免重复修正时间；浏览器测试比较真实时间与规则时间。
5. **手机横屏视野与操作不共屏**：增加短屏横向布局，将方向区和放泡泡按钮放到棋盘右侧，顶部保留暂停和时间。
6. **预览与正式布局的细微差异**：预览角色改为站在保证开放的格子，不再为预览清除箱子。
7. **Esc 暂停瞬间恢复**：阻止暂停快捷键的浏览器默认动作，保留明确的弹窗状态控制；新增单元测试及两种浏览器的定向回归。

## 复现

```bash
npm test
npm run build
npm run test:e2e -- --project=chromium --project=webkit --project=mobile-chromium --project=mobile-webkit --workers=2
```

Firefox 可在可正常启动的环境中单独运行 `npm run test:e2e -- --project=firefox --workers=1`。本机 Playwright 浏览器安装在项目 `.browsers/`，运行前需设置 `PLAYWRIGHT_BROWSERS_PATH`，见 README。

`scripts/production-smoke.mjs` 默认访问 `http://127.0.0.1:4180/`，可以通过 `QA_URL` 改为自己的隔离预览站点。报告与截图默认写入已忽略的 `.qa/production-smoke/`。可用 `QA_ARTIFACT_DIR` 调整该目录，`QA_OUTPUT` 单独指定报告路径，`QA_SCREENSHOT_PREFIX` 指定截图文件名前缀；自定义路径也应位于本地忽略目录。它会操作当前浏览器临时上下文的本地战绩，不影响已有个人浏览器资料。Nginx 上线仍需按实际域名 / TLS 配置重新做部署验收。
