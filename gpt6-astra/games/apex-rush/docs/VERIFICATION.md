# 疾风竞速验证记录

核对日期：2026-11-13。以下记录对应开发验证阶段，当时验证对象为工作区源码与其生成的本地分发文件，尚未创建 Git 提交、推送或服务器部署。后续源码发布状态以 Git 历史为准。

## 已核对的功能

- 三条赛道的封闭曲线、有限坐标、驾驶者左右方向、圈数与两圈完赛。
- 油门、刹车、漂移集气、松键小喷、氮气按下边缘与车型极速上限。
- 护栏和车辆碰撞减速；回正不增加里程；暂停冻结倒计时与比赛状态。
- 三套程序化 3D 场景、三种车型、赛道/车辆切换、帮助、画质/声音/模式设置。
- 手机模拟布局、多指输入模型、真实触点取消事件、失焦暂停及重新开始。
- 离线 HTML 无外部脚本、样式或 HTTP 请求，不包含开发诊断入口。
- 实际两圈比赛结算、圈速与个人最佳，返回大厅及刷新后读取纪录。
- 合集中的两款游戏搜索、空状态、键盘操作、下载、独立打开与子路径部署入口。

## 已处理的问题

1. 修正赛道横向坐标相对追尾镜头反向的问题，并验证右转对应驾驶者右侧。
2. 修正氮气加速量大于超速衰减量时可能持续超过车型极速的问题。
3. 锁存两帧之间的短氮气按下，避免低帧率丢失轻按。
4. 合并赛车静态几何，单车常显 Mesh 由 104 降至 24；保留独立车轮与尾喷。
5. 切换场景时同时释放 InstancedMesh 的实例缓冲与几何、材质、纹理。
6. 无转向自动油门测试会持续擦墙，实际完赛约四分钟；测试使用有界时间等待完整两圈，没有跳过赛程或改写结果。
7. 竖屏追尾镜头加大视野并拉远，避免车辆在窄屏下超出画面；触屏操作复测通过。
8. 重新比赛时清理上一局的碰撞/加速提示，增加新倒计时阶段的提示为空断言。
9. 排除 `.qa/`、`release/`、文档与测试文件的开发热重载监听，避免测试证据或离线构建打断正在进行的比赛。直接使用当前 Three.js 的 PCFShadowMap，去除旧阴影常量的自动降级警告。

合集完整 16 项验证后，赛车入口又在四种浏览器配置复核了下载、离线启动与暂停，共 4 项通过。最终竖屏镜头和新局提示清理改动另外通过真实浏览器截图及触点取消/重开测试；未重复执行不受影响的泡泡奇旅浏览器场景。

自然时间长跑执行期间，最后收敛了新局提示清理、开发监听忽略和阴影常量三个局部改动，没有改变比赛模拟；这些改动分别以定向浏览器用例和构建验证。最终分发包已经重新校验，不把较早的中间产物哈希写作最终产物哈希。
