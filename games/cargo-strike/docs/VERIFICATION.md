## 发现并修复的问题

- 侧道台阶提前撞到集装箱且受到顶棚阻挡：调整楼梯起点与顶棚长度，使用实际碰撞单测验证登高路径。
- 圆角武器与角色的几何索引格式不一致：合批前统一为非索引几何，重新检查控制台和画面。
- Esc 同时触发暂停与原生 dialog 取消，导致重新捕获鼠标：阻止该按键的浏览器默认操作，验证退出锁定、设置与恢复链路。
- 横屏触控按钮与较大的弹药数字接近：缩小触屏 HUD 字号，并重新验证真实触摸操作。
- 高台可越过低矮船舷：移动与站立校验统一限制在竞技场水平边界内，增加回归测试。
- 合集返回首页测试仍期望两个游戏：按实际新增作品需求更新为三个，保留导航和下载校验。
