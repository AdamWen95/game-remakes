# ADR 0001：独立的赛道坐标竞速模拟

- 日期：2026-11-13
- 状态：采用

## 目标与边界

在现有游戏合集增加可离线分享的 3D 单人赛车。游戏拥有独立 workspace 和依赖声明，按合集清单输出 HTML，不引用泡泡奇旅的运行时代码。

## 决定

`game/track.ts` 对封闭 Catmull-Rom 路线进行弧长采样，定义三条赛道及其物理宽度。`game/race.ts` 是不依赖浏览器与 Three.js 的确定性比赛状态机。车辆位置以累计里程 s 与横向偏移 d 表示；正 d 为驾驶者右侧。赛道曲率产生向外偏移，输入改变横向位置，漂移改变横移及车头姿态。它刻意使用街机近似，避免引入不需要的通用刚体框架。

模拟按 1/120 秒固定步长执行，主循环限制恢复帧长度为 0.1 秒，状态机二次限制单步 1/30 秒。浏览器后台或失焦自动暂停。暂停冻结倒计时、计时、氮气和位置；完赛结果冻结。回正不得增加里程。累计前向里程跨越两次终点才完成比赛，几何路径封闭保证不能从侧面跳过检查点。

`render/` 只读取模拟位置与姿态，负责程序化模型、静态场景合批、材质、阴影、拖尾及镜头。Three.js 无法初始化/上下文丢失时显示可见错误与重新加载操作。赛道/车型切换释放被移除的几何、材质和纹理；车轮、尾喷独立保留动画节点。

`game/input.ts` 收敛键盘与多指触控，按 pointerId 分别管理按压；保存瞬时氮气按下，防止低帧率时在两帧间丢失。UI 只调用明确动作，不能直接修改模拟。`storage.ts` 对版本化本地设置与纪录进行白名单校验，存储失败不伪装成持久成功。音频由 Web Audio 合成，仅在用户交互后解锁。

## 取舍与验证

车辆始终受赛道护栏约束，不提供开放世界、逆行、飞出赛道或真实悬挂。AI 使用独立车速和目标车道，不执行网络请求。纪录按赛道、车型、模式和竞速难度隔离；计时模式不因隐藏的 AI 难度选项而拆分纪录。

模拟测试覆盖封闭路线、左右方向、倒计时/暂停、输入边缘、漂移小喷、碰撞、时间边界及三条赛道两圈完赛。浏览器分别验证 DOM/输入与 WebGL 画面；单文件另行验证断网启动及实际完整比赛。源码变更与分发产物一并交付，移除新增清单条目及 workspace 可恢复原合集，不涉及已有泡泡奇旅存档迁移。
