# 单 HTML 分享版

整理日期：2026-11-13。模块化源码继续作为维护入口，额外生成一个可独立分发的 HTML 文件。

## 使用

从合集仓库根目录准备依赖后运行；下文未标明的资源路径均相对于 `games/bubble-journey/`：

```bash
npm ci
npm run build:single --workspace=bubble-journey
```

生成 `games/bubble-journey/release/bubble-journey.html` 与对应 `.sha256`。分享时只需发送 HTML；校验文件可选，不参与运行。根目录 `npm run build` 会复制同一内容到合集的 `dist/bubble-journey/index.html`。游戏源码入口 `index.html` 和本游戏常规 `dist/index.html` 仍依赖模块 / 资源文件，不是单文件分享版。

若希望通过链接游玩，可以将单 HTML 上传至静态网站，并使用实际托管地址。打包本身不会创建网站或公开链接。若附件预览器不执行脚本，先下载，再选择浏览器打开。

## 内容与构建边界

- Phaser、TypeScript 编译后的游戏逻辑、CSS、favicon 和第三方许可均内嵌；角色纹理、地图及声音由浏览器程序化生成。
- 复用已锁定的 Vite，使用单入口 IIFE 格式，不新增依赖、不引用 CDN。脚本与样式在内存中构建，最终只写入 `release/`。
- 构建会拒绝额外脚本分块、未内嵌资源或开发诊断接口。HTML 内含内容安全策略，禁止网络连接，只允许内嵌脚本 / 样式和 `data:` / `blob:` 图像。
- `npm run build:single` 不执行常规部署打包，不改写 `dist/`、已有 `.tar.gz` 发布包或服务器配置。
- 第三方 MIT 许可文本作为非执行文本保留在 HTML 中；本项目的原创游戏代码和资源保持原样。
- 分享文件只包含游戏代码与资源，不包含本机战绩、真实主机地址、运维记录或访问凭据。

这与参考项目的“模块化维护、单 HTML 交付”做法一致；参考项目使用 esbuild，本项目复用现有 Vite。未复制参考游戏源码或美术。[参考构建脚本](https://github.com/riba2534/claude-opus-5-5-demo/blob/main/qq-speed/build.mjs)

## 浏览器行为

- 下载后的 HTML 可通过 `file://` 直接打开，不需要启动 HTTP 服务，也不需要联网加载 Phaser、字体、图片或音频。
- 声音在用户首次交互后开启。浏览器静音或系统音量设置仍然有效。
- 战绩、角色和音效偏好保存在接收者自己的浏览器。不同浏览器、文件位置、隐私模式之间不保证共享或持久化；存储不可用时会降级为当前会话记录并给出提示。
- 手机的文件打开方式由系统 / 浏览器决定。网页触屏布局有自动化模拟验证，附件预览和真实手机系统打开流程未逐机验证。
- 单文件版的内联内容安全策略不适合直接套用常规站点示例中的严格 `script-src 'self'` 响应头。托管时需允许该文件的内联脚本 / 样式或配置对应内容哈希；现有服务器的常规多文件版本不需要修改。

## 验证

```bash
npm run build:single --workspace=bubble-journey
npx playwright install chromium webkit
npm run test:single --workspace=bubble-journey
```

测试将 HTML 复制到一个只含该文件的独立目录，以 `file://` 打开，启用浏览器离线模式，并检查没有额外文件 / 网络资源请求。覆盖角色和地图选择、音频解锁、键盘 / 触屏、暂停 / 重开、自然结束的完整对局，以及本地存储不可用时的降级。

`playwright.single.config.ts` 独立于常规网站测试配置，不启动 Vite 或访问部署服务器。原始截图与 trace 保存在已忽略的 `.qa/single-html/`，HTML 报告在 `playwright-report/single/`。Firefox 的本机启动限制仍见既有验证说明，不能据其他内核的通过结果推断已验证 Firefox。
