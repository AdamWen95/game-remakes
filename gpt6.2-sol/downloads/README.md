将 HTML 保存到本机并用浏览器打开即可开始。ZIP 根目录只有同一个 HTML 文件。角色、地图、视觉特效和声音均内置，可全程离线游玩。浏览器允许本地存储时会记住设置、最高积分和累计胜场。

使用 WASD 或方向键移动，按空格放置泡泡，按 Esc 暂停。手机布局提供方向键和放泡泡按钮。
