# 0001 战斗模拟与实时渲染

日期 2026-11-19，状态为采用。

游戏需要在桌面和触屏浏览器离线运行，并保持画质选项下的对局行为一致。战斗推进采用 60 Hz 固定步长，支持注入随机种子进行逻辑回归。浏览器将键鼠和触控转成统一输入，Three.js、HUD 和音效根据模拟状态及事件播放反馈。暂停时模拟计时一并停止。

`arena.ts` 提供有高度的阻挡体、台阶和出生点。碰撞、遮挡、小地图和场景使用同一份几何数据。AI 在地面网格上寻路，左舷高架开放给玩家。今后若要让 AI 登高，需在导航中显式加入楼梯和高架的连接，并覆盖楼梯上下与高低位交火。可破坏掩体或多人联网会改变几何、时间或随机数的一致性边界，需独立设计。
